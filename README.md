# とけいヒーロー！

年長（5〜6歳）くらいの子どもがスマホのブラウザで遊びながら、アナログ時計の読み方を練習できるミニゲームです。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。ビルドや外部ライブラリは不要です。

- **やさしい**: 「◯じ」ぴったり
- **ふつう**: 「◯じ」と「◯じ30ぷん」
- **チャレンジ**: 5分刻み
- 1プレイは6問
- 正解すると紙吹雪・コンボ・効果音・読み上げ
- 間違えても減点せず、針のヒントを表示して再挑戦
- プレイ終了ごとに「ごほうびシール」を1枚獲得
- シールとベストコンボは `localStorage` に保存

## テスト

Node.js でコアロジックのテストを実行できます。

```bash
node --test tests/core.test.js
```

ブラウザ表示はモバイル幅（390×844）を基準に確認しています。

## デプロイ

静的サイトなので GitHub Pages / Cloudflare Pages などにそのまま配置できます。Cloudflare Pages の場合はビルドコマンド不要、出力先はリポジトリのルートです。
